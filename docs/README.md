# Shared Contracts and Documentation Ownership

## `CONTRACTS.md` is authoritative

`docs/CONTRACTS.md` is the shared Team Contract v3.0 maintained through
the team agreement.

**Do not regenerate, replace, casually edit or independently reinterpret
it.** Copy the canonical version supplied by the team into this
repository unchanged.

`INTEGRATION_CONTRACT.md` is the Agent service-specific companion. If it
conflicts with the shared contract, the shared contract wins; raise the
discrepancy with the service owner rather than silently changing either
document.

## Related documents

-   `AGENTS.md` --- primary persistent instructions for Codex.
-   `IMPLEMENTATION_PLAN.md` --- engineering plan and architecture
    decisions.
-   `DELIVERABLE_MAPPING.md` --- official AGT tasks mapped to
    implementation/tests.
-   `INTEGRATION_CONTRACT.md` --- Agent integration boundaries.
-   `PROGRESS.md` --- current project status.
-   `COPILOT_MASTER_PROMPT.md` --- reusable Copilot/session context.
-   `.github/copilot-instructions.md` --- Copilot compatibility
    instructions.

Update `PROGRESS.md` as work is completed. Update the plan/mapping only
when an approved architecture or scope decision changes.
